АИС «PYM-Финанс»
Учебный проект (ВКР). Выполнил: Сариогло С.Д., гр. ИДБ-22-10.
Веб-приложение для планирования движения денежных средств (Cash Flow) организации и отслеживания кассовых разрывов.
О чем проект
Основная идея — помочь бухгалтеру или экономисту заранее увидеть, в какой день на расчетном счете может не хватить денег на обязательные платежи (зарплата, налоги, аренда и т.д.).
В системе задается начальный остаток на счете и список финансовых правил (приходы и расходы). Правила могут быть разовыми, регулярными (раз в неделю, раз в месяц и т.д.) или каждый рабочий день. На основе этих правил программа строит прогноз баланса по дням на выбранный период (30, 90, 180 или 365 дней), рисует график и подсвечивает дни, когда баланс уходит в минус.
Также можно кликнуть по графику, посмотреть какие именно операции запланированы на конкретный день, добавить новую операцию или загрузить правила списком через JSON.
Из чего состоит (стек)
Проект разбит на несколько сервисов, которые запускаются в Docker:
Фронтенд — React, TypeScript, Vite. График строится через библиотеку Recharts.
pym-gateway (Java 21, Spring Boot) — входная точка (API Gateway) и авторизация пользователей по JWT-токенам.
pym-data-service (Go) — сервис для работы с базой данных (сохранение и получение правил, настроек баланса, сброс демо-данных).
pym-predictor (Python, FastAPI) — сервис расчета прогноза движения средств по дням.
PostgreSQL 15 — база данных (при первом запуске автоматически создаются таблицы и заливаются тестовые данные из PYM/init-db/init.sql).
Если бэкенд не запущен, фронтенд может работать автономно в браузере (сохраняет данные в localStorage и считает прогноз локально).
Как запустить
Вариант 1. Полный запуск через Docker (со всеми сервисами и БД)
В корне проекта выполнить:
code
Bash
docker compose up --build
После сборки контейнеров:
Веб-интерфейс будет доступен по адресу: http://localhost:8099
API шлюз: http://localhost:9800
pgAdmin (для просмотра БД): http://localhost:5050
Вариант 2. Только фронтенд (для быстрой проверки интерфейса)
Если нужен только интерфейс без поднятия докера:
code
Bash
npm install
npm run dev
Откроется на http://localhost:3000.
